# Cайт с ботом «Ясный переводчик»

## Общая информация о проекте

Цели и задачи проекта: разработать сайт с ботом, который будет переводить сложные тексты на «ясный язык». Это нужно, чтобы устранить барьеры, которые люди с ОВЗ 
могут испытывать в повседневной жизни.

### Общая характеристика деятельности организации

Наименование заказчика: благотворительный фонд «Лучшие друзья». Фонд состоит из волонтерского движения, которое помогает устраивать людей с ОВЗ на работу, начать самостоятельно жить и находить хороших друзей.

### Задачи проекта

** 1.Разработка многостраничного веб-сайта **
    Создать многостраничный сайт с использованием HTML, CSS и JavaScript, обеспечивающий структурированное и удобное взаимодействие пользователей с информацией о проекте, его 
участниках, ресурсах и функционале бота. 
** 2.Реализация взаимодействия с партнёрами **
    Обеспечить интеграцию и отображение информации о партнёрах проекта, таких как "Наш солнечный мир", "Лучшие друзья" и Московский политехнический университет, а также 
организовать взаимодействие с ними в рамках сайта. 
** 3.Создание функционала для взаимодействия с ботом **
    Реализовать интерфейс, позволяющий пользователям вводить или загружать сложные тексты и получать их упрощённые версии, а также обеспечить удобство и доступность этого сервиса. 
** 4.Обеспечение безопасности и персонализации **
    Реализация систем регистрации и авторизации для пользователей, что позволяет обеспечить безопасный доступ к функционалу сайта и персонализировать взаимодействие. 

## Структура сайта

Сайт состоит из следующих разделов:

** 1.Главная страница **
    На главной странице размещена краткая информация о проекте. Также здесь расположены основные навигационные элементы, позволяющие пользователям легко перейти к другим разделам сайта. 
** 2.Страница "О проекте" **
    Описание бота, основные принципы адаптации текста, как пользоваться. В этом разделе раскрываются цели, принципы работы и основные преимущества использования нашего сервиса.
** 3.Страница "Участники" **
    На странице находятся все ФИО и фото участников в проектной деятельности.
** 4.Страница "Журнал" **
    Раздел содержит публикации и новости, связанные с развитием проекта. Здесь размещаются статьи, отчёты о обновлениях и достижениях команды.
** 5.Страница "Ресурсы" **
    Страница содержит перечень партнеров по проектной практике.
** 6.Страница "Бот" **
    Онлайн чат бот ясный переводчик
** 7.Страницы "Регистрация" и "Вход" **
    Эти разделы предназначены для регистрации новых пользователей и входа в систему для авторизованных участников. Они обеспечивают безопасность и персонализацию доступа к функционалу сайта. 

## Техническая реализация

### Стек и архитектура

**Фронтенд** — HTML5‑шаблоны в `/public`, CSS3 (Flexbox, Grid, переменные), Vanilla JS (ES2022) для форм и чата.  
**Бэкенд** — Node.js 20 LTS, Express 4.19, better-sqlite3 для локальной базы, https‑proxy‑agent для внешних запросов, Gemini Flash API для генерации ответов ИИ, bcrypt для хеширования паролей, axios для HTTP‑запросов.

### Структура проекта

- `src/` — серверный код: `ai.js`, `db.js`, `config.js`, `server.js`.  
- `public/` — статические страницы, стили, скрипты, изображения.  
- `messenger.db` — локальная SQLite база данных для пользователей и сообщений.

### Сервер и API

- Маршруты: 4 статических (`/`, `/chat`, `/login`, `/register`), 2 API (`/api/chat`, `/api/messages/:id`).  
- Middleware: `express.json()`, `helmet()`, `cors()`, проверка `X-User` (заменяется на JWT).  
- API `/api/message`: принимает текст, сохраняет сообщение, вызывает AI (`aiMsg()`), возвращает ответ.  
- Логирование: через `console`, рекомендуется заменить на `pino`.

### База данных

- Таблицы:  
  - `users` — id, username, хеш пароля, дата создания  
  - `messages` — id, user_id, роль (`user` или `assistant`), содержимое, дата  
- Связь по `user_id`, каскадное удаление.

### Клиентский JS

- `chat.js`:  
  - `GET /api/messages/:userId` — загрузка и отображение сообщений с авто‑scroll  
  - `POST /api/message` — отправка сообщений, обновление UI и базы данных  
- `registration.js`, `login.js`: регистрация/вход, хранение токена в LocalStorage.  
- Код использует ES‑modules, работает в современных браузерах.

### Переменные окружения (`.env`)

- `PORT` — порт сервера (по умолчанию 3000)  
- `GEMINI_API_KEY` — API ключ для Gemini Flash  
- `FORWARD_PROXY` — прокси (опционально)

### Работа с NLP моделью

- Входной текст пользователя отправляется на сервер, вызывается локальная или облачная модель (через API).  
- Модель упрощает сложные формулировки, возвращая обработанный ответ для пользователя.  
- Это делает систему особенно полезной для людей с когнитивными нарушениями.
