# Проектная практика

## Задание на проектную практику

### Введение

Задание состоит из двух частей.
    Первая часть является общей и обязательной для всех студентов. 
    Вторая часть вариативная. 
В рамках прохождения проектной практики нам было поставлено 
задание по разработке и реализации веб-сайта, направленного на создание 
информационной платформы для поддержки и повышения доступности 
коммуникации для людей с ментальными инвалидностями. 
Основной целью проекта является создание интерактивного сервиса, включающего 
автоматизированного бота, способного переводить сложные тексты в более 
понятную и доступную форму. 

---

### 1. Основные задачи проектной практики

1. **Разработка многостраничного веб-сайта**
   Создать многостраничный сайт с использованием HTML, CSS 
и JavaScript, обеспечивающий структурированное и удобное 
взаимодействие пользователей с информацией о проекте, его 
участниках, ресурсах и функционале бота.

2. **Реализация взаимодействия с партнёрами**
   Обеспечить интеграцию и отображение информации о 
партнёрах проекта, таких как "Наш солнечный мир", "Лучшие 
друзья" и Московский политехнический университет, а также 
организовать взаимодействие с ними в рамках сайта.

3. **Создание функционала для взаимодействия с ботом**
   Реализовать интерфейс, позволяющий пользователям вводить 
или загружать сложные тексты и получать их упрощённые версии, а 
также обеспечить удобство и доступность этого сервиса.

4. **Обеспечение безопасности и персонализации**
    Реализация систем регистрации и авторизации для
пользователей, что позволяет обеспечить безопасный доступ к 
функционалу сайта и персонализировать взаимодействие.
